# Agent Orientation — Harry's Birthday Card 2026

## Project Purpose

Standalone browser demo: a 3D "Happy Birthday" card for Harry Baya with music, wombats, letter cubes, ladders, burrows, and confetti.

## Directory Layout

```
birthday-card-2026/
├── index.html              # Main demo
├── audio/                  # Music and timing data
├── models/                 # wombat.stl
├── lib/                    # Three.js + Boppers helpers
├── scripts/                # Asset generator
├── README.md
└── AGENTS.md               # This file
```

## Hard Constraints

1. Keep everything self-contained in this directory.
2. The wombat STL (`models/wombat.stl`) is large; do not duplicate it unnecessarily.
3. Audio is generated by `scripts/generate_happy_birthday_wav.py`; commit its outputs in `audio/`.
4. Use CDN for Three.js when possible, but keep local fallbacks in `lib/`.

## Key Technologies

- Three.js r128
- Boppers engine helpers (`lib/boppers-engine.js`, `lib/boppers-symbols.js`)
- `soundfont-player` (loaded from unpkg CDN) for real instrument samples
- Web Audio API

## Build / Test

1. Run `python3 scripts/generate_happy_birthday_wav.py` to regenerate audio.
2. Open `index.html` in Chrome.
3. If changing `index.html`, run the parent project's smoke test:
   `python3 ../scripts/smoke_test_boppers_demo.py --demo birthday-card-2026/index.html --duration 8`

## Common Change Points

- Music tempo: edit `TEMPO_BPM` in `scripts/generate_happy_birthday_wav.py`.
- Wombat behavior: edit the `Wombat` class in `index.html`.
- Letter animation: edit `updateLetters()` in `index.html`.
- Confetti physics: edit `updateConfetti()` in `index.html`.

## Deployment

This repo is designed to be deployable as static files to any web host.
